# jlc-cli v1 设计边界

本文记录本次重写采用的工程决策。需求来源是仓库根目录的 [PRD](../.md)。实现完成度与真实站点验收须分别记录，不能用本文件代替验收结果。

## 责任划分

外部 AI Agent 理解用户业务需求、询问缺少的选择并在获准后建议参数。CLI 提供业务命令，保存任务状态，验证输入，驱动网站，回读实际结果。Obscura 提供可保留和接管的浏览器会话；站点适配器识别 jlc.com 当前页面的账号、参数、订单和支付状态。网站仍负责文件解析、计价、建单和余额扣款。

CLI 不内置模型。`default` 与 `auto` 描述参数决策来源，不证明调用 Agent 已经取得授权：默认模式不把网站预选值视为用户选择；自动模式须先有用户让 Agent 帮助选填的意图。已有明确选择优先，不能静默覆盖。网站修正值或新出现条件参数时，需返回差异或缺失项。

## 任务与结果

上传、登录、付款等有持续上下文的操作使用持久化任务标识。任务关联所使用的账号配置、页面和业务对象，正常结果与诊断日志分离。进程退出不会凭空把待确认的提交或支付标为失败；后续观察读取真实状态，不能重复产生业务副作用。

任务输出使用版本化 JSON envelope。业务状态与进程退出码同时表达成功、缺输入、待人类确认、登录失效、待接管和结果未知。调用 Agent 应先检查状态和下一步提示，不能只检查进程是否结束。

持久化数据分为浏览器会话、配置、任务、回调投递记录和诊断素材。浏览器会话属于敏感本地资料，不写入仓库；常规输出和回调不包含 Cookie、令牌、密码或短信验证码。诊断素材可能含当前页面资料，应按本地账号资料保护，不自动上传外部服务。

## 登录、二维码与回调

登录从当前页面实际提供的方式开始；页面未提供的方式返回不可用，不能仅凭命令参数枚举宣称支持。人类完成扫码、短信或滑块等验证。CLI 读取当前账号身份或认证状态后，才认定登录成功；二维码消失、页面跳转、弹窗关闭均不是充分证据。

扫码交付的是当前登录任务对应的可展示二维码素材及页面信息。二维码刷新、过期或方式切换时，旧素材不能继续作为有效二维码。任务状态明确表达仍在等待还是已通过验证。

调用方可选择等待最终 JSON、立即消费 JSONL 事件，或显式配置回调。回调事件不包含凭据或个人资料，事件 ID 用于接收端去重。回调地址限定本机回环 HTTP 或 HTTPS；HMAC 密钥从指定环境变量读取，不通过命令值或输出暴露。投递失败与登录失败是不同结果，重试回调只能重投通知，不重新登录或重复业务操作。

## 文件、参数和提交

上传前检查文件存在及可读性，保存文件身份与上传任务关联。仅使用下单页面原生支持的格式，不转换 EDA 源文件。上传完成、解析完成、预览可用是分别核实的状态。

预览使用本次上传对应的网站结果，返回真实页面链接或可查看素材。不会用旧预览补齐本次结果，不内置 Gerber 渲染器。页面原生支持范围、参数候选值和依赖关系须通过实际页面核对；测试夹具只能验证处理逻辑，不能证明生产网站当前支持相同范围。

报价绑定当前文件与参数。参数变化使旧报价和检查摘要失效。建单前检查完整提交摘要，包括网站流程要求的收货信息；只有明确的提交命令才可能建单，报价与参数设置不自动建单。提交未知时查询关联订单，不重按提交按钮。

## 每笔付款的确认

付款分为准备摘要、人类确认、执行与结果核实。摘要绑定当前账号、订单、应付金额和嘉立创余额支付方式。初始化授权、自动参数模式、CDP 接管和开发授权都不能替代本次付款确认。

执行前重新核对摘要。如果账号、订单、金额或支付方式变化，旧确认失效。点击成功、跳转完成或弹窗关闭不能证明支付成功；只有与当前订单关联的可验证支付状态才可返回已支付。超时或证据冲突进入结果未知状态，后续先查询，不能重新扣款。

## 接管与自动核实

异常时保留对应浏览器和任务，返回当前步骤、预期与实际现象、页面身份、CDP 连接信息及可获取的诊断素材。浏览器退出或 CDP 不可达时如实报告，不伪造可接管状态。CLI 通过本机中继保留 Obscura 上游连接，仅让一个客户端使用同一会话；不直接连接会在客户端退出时丢失页面的 Obscura 原始 CDP。CDP 限制为本机回环地址，远程使用须先建立受保护的本机转发。

接管方先获取任务页面的控制租约，再操作同一页面；持有租约期间 CLI 不并行写入该页面。接管结束须释放租约。观察流程先只读核实实际状态，租约释放或到期且前置条件满足时，无需额外恢复命令即可更新或推进任务。原参数设置、提交或付款尚未发起且适配器确认可以继续时，在同一操作锁内重新执行原步骤；付款仍须有匹配、有效、未使用的确认凭据，提交仍须核对文件、参数和报价。已有提交或扣款意图记录时只核实结果，不自动重做。

自动恢复依赖正在运行的业务观察过程。关闭观察 CLI 后没有常驻业务观察器；浏览器中继仍可保留浏览器会话，重新启动任务观察才能继续核实业务。浏览器或页面被关闭后，保留的任务资料可供诊断，但不保证仍可接回同一现场。

## 范围与支持

账户配置彼此隔离；账号查询只返回网站可见值，网站脱敏则保留脱敏。退出清理选中的 CLI 配置本地会话并停止 CLI 自有浏览器，不替用户注销外部 CDP 浏览器；返回 `externalSessionUnchanged` 时外部会话仍然有效。订单查询覆盖页面实际可见的 PCB/FPC 信息，不含 FPC 新下单、取消、退款或发票。

嘉小智一次命令发送一条文本并返回对应回复，可复用当前页面对话。不承诺附件、流式传输、可移植历史或独立多会话管理。其回复不是用户生产参数决定或付款授权。

交付采用 npm 包并包含 Skill，Node.js 最低版本 22.12，目标平台为 macOS、Windows、Linux。CI 检查平台上的 CLI 构建与本地测试；Obscura 启动、实际网站流程及 CPU 架构必须分别记录验证。Chrome 诊断通路不能替代 Obscura 验收。详见 [验收记录与步骤](acceptance.md)。
