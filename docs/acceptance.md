# 验收步骤与证据边界

本文件区分本地测试、浏览器集成验证和 jlc.com 真实业务验收。只有记录了环境、命令、实际结果与可核查证据的项目才能标为通过。仓库中的测试夹具不是真实订单、报价或付款记录。

本次开发授权允许实现和本地验证，不包含替用户建立真实订单或余额扣款。真实业务验收须使用用户授权的账号、文件与业务操作；付款还须取得针对该笔账号、订单、金额和方式的人类确认。

## 记录格式

每次验收保存日期、系统/CPU/Node/浏览器版本、所用提交、匿名账号配置名、命令、预期、实际、证据路径和结论。真实订单号和截图等本地证据可保留在用户控制的位置，公开报告仅使用必要且经脱敏的信息。不得记录 Cookie、密码、短信验证码、回调密钥或浏览器会话文件。

失败或未执行项应写出实际原因与剩余条件。未完成的真实账号与付款验证不由模拟结果补齐；上线结论必须保留这些限制。
